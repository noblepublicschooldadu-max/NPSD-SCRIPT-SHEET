# School image assets

No verified photograph of the actual Noble Public School Dadu campus was present when the redesign was implemented.

## Replace the hero placeholder

1. Ask the school owner for a photograph of the actual campus that is approved for public use.
2. Save the approved file here as `campus-photo.jpg` (or choose another filename and update both image references in `src/app/page.tsx`).
3. In `src/app/page.tsx`, replace the two `/images/campus-photo-placeholder.svg` references with `/images/campus-photo.jpg`.
4. Update the hero image alt text to describe what is genuinely visible in the approved photo.
5. Verify the crop on small phones and wide screens.

The current `campus-photo-placeholder.svg` is a labeled illustration only. It is not a photo of the school and must not be described as one. Do not add identifiable children's photographs without the school's permission and appropriate parent/guardian consent.
